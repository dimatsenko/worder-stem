# Worder

## Запуск

Потрібні Node.js 22.12+ і Python 3.10+. Команди виконайте в корені проєкту.

```sh
npm ci
npm run dev
```

Відкрийте [локальний сайт](http://127.0.0.1:8765/).

## Структура

- `src/` — Vue-тренажер і стилі
- `templates/`, `content/` — HTML-шаблони та юридичні тексти
- `assets/`, `public/` — словник, зображення, шрифти та іконка
- `scripts/`, `tests/` — збирання й перевірки
- `docs/` — документація
