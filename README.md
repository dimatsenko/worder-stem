# Worder — вебзастосунок для вивчення слів

Сайт містить головну сторінку, двомовні юридичні документи та навчальний
застосунок із 5 943 англійськими словами рівнів A1–C1. Навчання побудовано
на **Vue 3, Composition API та компонентах `.vue`**. **Vite** запускає сервер
розробки й готує оптимізовані файли для публікації.

**Для захисту почни з [docs/DEFENSE.md](docs/DEFENSE.md):** там є карта коду,
схема архітектури, пояснення алгоритму й короткий сценарій демонстрації.

## Швидкий запуск

Потрібні Node.js 22.12+ (також підтримується 20.19+) і Python 3.10+.
Версії залежностей зафіксовані в `package-lock.json`.

```sh
npm ci
npm run dev
```

Відкрий <http://127.0.0.1:8765/> або <http://127.0.0.1:8765/app.html>.
Vite оновлює змінені JavaScript, Vue-компоненти та CSS у браузері.
Після змін у `templates/`, `content/legal/` або вихідних CSS-файлах запусти
`python3 scripts/build.py`: він перегенерує сторінки та об'єднані стилі.

Не відкривай HTML подвійним кліком і не використовуй Python HTTP-сервер для
вихідної папки: `.vue` та npm-імпорти потребують Vite. Для готового `dist/`
звичайний статичний HTTP-сервер підходить. Відкриття `app.html` через `file://`
показує пояснення запуску.

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Підготовка HTML/CSS і локальний Vite-сервер |
| `npm run build` | Повна production-збірка в `dist/` |
| `npm run build:site` | Та сама збірка; сумісний псевдонім команди збірки |
| `npm run preview` | Перегляд готового `dist/` на порту 8765; спершу зупини `dev` |
| `npm test` | Перевірки алгоритмів, збереження та HTML-шаблонів |
| `npm run test:browser` | Поведінкові й візуальні тести готової збірки |
| `npm run format` | Єдине форматування JavaScript і Vue через Prettier |
| `npm run format:check` | Перевірка форматування без редагування |
| `npm run check` | Збірка, модульні тести, форматування та браузерні тести |

Для браузерних тестів один раз встанови Chromium:

```sh
npx playwright install chromium
npm run check
```

Тести запускають окремий preview на порту 8771 та використовують ізольоване
сховище. Якщо порт зайнятий, звільни його або зміни обидві адреси у
`playwright.config.js`. `PLAYWRIGHT_CHROMIUM_EXECUTABLE` дозволяє вказати
наявний Chromium. Візуальні еталони створено на macOS; на інших ОС ці два
тести пропускаються, оскільки системні шрифти відрізняються.

## Де що знаходиться

```text

  main.js                     Монтує кореневий Vue-компонент
  App.vue                     Підключає стан і спільні команди
  components/                 Окремі частини інтерфейсу
    StudyScreen.vue           Вибирає екран, містить діалоги
    StudyCard.vue             Слово, переклад, тест і кнопки
    StudyToolbar.vue          Налаштування, режим, статистика, undo
    LearningSettings.vue      Спільний блок налаштувань
    DailyGoal.vue             Повзунок денної цілі
    LevelOptions.vue          Вибір рівнів A1–C1
    CompleteScreen.vue        Результат завершеної сесії
    WordHeading.vue           Слово, частина мови, транскрипція
    WordExample.vue           Приклад із виділенням слова
    AppButton.vue, Icon.vue   Повторно використовувані кнопки та іконки
  composables/
    useStudyApp.js            Координує команди, анімацію й стан
    study-context.js          Ключ provide/inject для команд
  session.js                  Черга карток і переходи після відповіді
  scheduler.js                Інтервальне повторення SM-2
  quiz.js                     Чотири варіанти перекладу
  history.js                  Історія скасування відповідей
  storage.js                  Перевірка й збереження localStorage
  card-motion.js              Анімації та жести
  speech.js                   Озвучення через браузер
  formatters.js               Українські словоформи та підписи
  bootstrap.js                Повідомлення про file:// і помилки запуску
src/scripts/main.js           Поведінка головної та юридичних сторінок
src/styles/                   Наявні стилі за компонентами й секціями
content/legal/                Тексти документів українською й англійською
templates/                    Спільний HTML-каркас, сторінки та секції
assets/data/english.json      Каталог зі стабільними ID слів
assets/fonts/                 Локальний Manrope
assets/mascot/, screenshots/   Зображення сайту
public/favicon.ico            Іконка Worder; Vite копіює її в корінь готового сайту
scripts/build.py              Безпечний рендерер HTML-шаблонів і CSS
scripts/copy-public-assets.mjs Копіює JSON-каталог у готовий сайт
vite.config.js                Збірка чотирьох HTML-сторінок і Vue
tests/                        Перевірки логіки, браузера та вигляду
docs/                         Пояснення проєкту та матеріал для захисту
```

Редагуй джерела в `src/`, `templates/` і `content/`.
**Згенеровані файли не редагуються вручну:** `index.html`, `app.html`,
`terms.html`, `privacy.html`, `site.css`, `app.css`, `legal.css` та `dist/`.
Кореневі HTML/CSS — проміжний результат Python, який використовує Vite.
Публікується тільки `dist/`; тести, документи та вихідний код туди не входять.

## Основні рішення

- Vue відповідає за відображення й події; алгоритми навчання — звичайні JS-модулі.
- Шаблони `.vue` компілюються під час збірки. Браузер не компілює HTML-рядки.
- Дані йдуть у компоненти через `props`; команди доступні через `provide/inject`.
- `useStudyApp` публікує готові копії стану через `shallowRef`. Компоненти не
  змінюють збережений прогрес безпосередньо.
- Анімації чекають `nextTick`, а повторні натискання блокуються на час переходу.
- Обробники глобальних подій і запит каталогу очищуються при демонтажі компонента.
- Прогрес зберігається під тим самим ключем `worder.web.v1`; попередні збереження
  сумісні. Акаунта та синхронізації між пристроями немає.
- Денна ціль 5–30 — орієнтир у статистиці. Навчання можна продовжувати без денного ліміту.
- Статичні сторінки зберігають спільні шаблони. Python використовує лише стандартну
  бібліотеку; окремого backend-сервера для сайту немає.

Підхід до компонентів відповідає офіційній документації
[Vue SFC](https://vuejs.org/guide/scaling-up/sfc) та
[`<script setup>`](https://vuejs.org/api/sfc-script-setup).
Докладні правила черги й відповідність iOS-версії — у [WEB_APP.md](docs/WEB_APP.md).

## Перевірка рефакторингу

Перевірено 30 JavaScript-тестів, 3 Python-тести та 12 браузерних тестів.
Шість еталонних скриншотів екрана рівнів, навчання й налаштувань на ширинах
390 і 1440 px збігаються піксель у піксель з версією до рефакторингу.
Додаткова локальна перевірка 20 000 переходів відповідей дала однакові результати
старого й нового алгоритму. Остання перевірка: 17 листопада 2026 року.
